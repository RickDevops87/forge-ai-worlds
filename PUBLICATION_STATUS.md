# Reusable AI security test environments — public research snapshot

This public repository is a curated snapshot of Forge-authored research and development, prepared for research transparency and grant review. It is not a representation of a finished commercial service.

**Current limitations:** Experimental isolated world packs and world_harness runner; infrastructure isolation and scenarios must be independently qualified before treating them as safe for hostile agents.

Private evidence, credentials, personal notes, internal tooling, original private Git history and Forge CLI are intentionally excluded. This public snapshot does not include those resources or imply public rights to them.

Work is published as-is for review; follow the main README for the implementation and available tests.
